# Lens, Optics, and Focus

Choose one exact full-frame-equivalent focal length per frame. Use a director's lens ladder as scene-conditioned options, not as a list to include in the prompt.

## Selection Rules

- **Spatial wide:** architecture, ensemble relations, foreground pressure, monumental scale, or designed distortion.
- **Human normal:** balanced environmental intimacy, observation, dialogue, or ritualized staging.
- **Compression/detail:** surveillance, private distance, graphic isolation, landscapes in layers, or exact object inserts.
- Change camera distance with focal length. A long lens from the same close position is not a valid substitute for a wide lens.
- State one focus endpoint and one depth strategy. If a rack focus is implied, name only the start and final subject.
- Default to spherical rendering. Use restrained anamorphic edge behavior only for grammars that benefit from horizontal compression or flare, and never add decorative flares without a visible source.

## Focus Strategies

- **Deep staging:** foreground, action, and consequence readable together.
- **Moderate relational focus:** primary subjects sharp while environment remains meaningful.
- **Selective plane:** one spatial plane sharp to create separation or concealment.
- **Close-focus falloff:** hero prop or face sharp with controlled contextual softness.
- **Split-plane clarity:** foreground clue and distant subject both legible; use only when spatially plausible.
- **Rack endpoint:** attention transfers from one named anchor to another; do not imply repeated focus hunting.

## Failure Gate

- Regenerate if wide-lens perspective looks telephoto-flat or long-lens staging looks spatially stretched.
- Reject arbitrary oval bokeh, horizontal flare, fisheye curvature, miniature blur, or excessive edge smear.
- Reject shallow focus that erases the composition geometry or secondary narrative anchor.
- Reject a lens choice that contradicts the director's camera distance and blocking logic.
